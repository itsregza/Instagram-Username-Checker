<p align="center">Check and find Instagram name availabilities. </p>

## Setup

```
pip install -r requirements.txt
```

## Usage

1. Put your proxies in `proxies.txt` (optional), one per line as `host:port:user:pass`
2. Run it

```
python checker.py
```

3. Pick an option
   - `1` check a single username
   - `2` check every username in `usernames.txt` (one per line)

Available usernames get saved to `available.txt`.

## Notes

- If you run proxyless it'll likely be rate limited after like 5 checks.
